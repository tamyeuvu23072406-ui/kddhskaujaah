Truyện/

Danh sách tập

    Truyện này chưa có tập nào — hãy thêm thư mục tập và ảnh vào trong thư mục truyện.

    Thêm truyện mới

    Toàn bộ nội dung nằm trong thư mục manga/. Chỉ cần thêm thư mục và ảnh theo đúng cấu trúc, site sẽ tự nhận.

    1. Cấu trúc thư mục

    manga/
├── Ten-truyen-1/
│   ├── info.json          ← (tuỳ chọn) tên hiển thị, tác giả, mô tả
│   ├── cover.jpg          ← (tuỳ chọn) ảnh bìa; bỏ trống sẽ lấy trang đầu
│   ├── Tap-01/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── 003.jpg
│   └── Tap-02/
│       └── …
└── Ten-truyen-2/
    └── …

    2. Quy tắc sắp xếp

    • Ảnh được xếp theo tên file: 001.jpg, 002.jpg, … 010.jpg — luôn dùng số đệm 0 ở đầu để thứ tự đúng.
    • Tập (part) xếp theo tên thư mục: Tap-01, Tap-02… — cứ thế tự động lên danh sách.
    • Định dạng ảnh hỗ trợ: .jpg .jpeg .png .webp .gif .avif.

    3. Cập nhật danh sách

    Sau khi thêm ảnh, cần tạo lại manga/manifest.json — bằng một trong hai cách:

    • Tự động (khuyên dùng): GitHub Action .github/workflows/update-manifest.yml đã có sẵn — mỗi lần bạn git push, danh sách tự cập nhật.
    • Thủ công: chạy python3 tools/build_manifest.py rồi push cả file manifest.json.

    4. File info.json (tuỳ chọn)

    {
  "title": "Hành Trình Của Gió",
  "author": "Tên bạn",
  "description": "Mô tả ngắn về truyện…",
  "status": "Đang tiến hành",
  "cover": "cover.jpg"
}

    5. Đổi tên / giao diện site

    Sửa config.js ở thư mục gốc: tên site, câu giới thiệu, màu nhấn…
